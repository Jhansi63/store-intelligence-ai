# Store Intelligence AI

AI-powered retail analytics system using CCTV footage.

## Features

* Visitor detection
* Visitor tracking
* Analytics dashboard
* Video upload
* YOLOv8 integration

## Tech Stack

* Python
* Streamlit
* YOLOv8
* OpenCV
* SQLite

## Run Project

```bash
python -m streamlit run dashboard/dashboard.py
```
